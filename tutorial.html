純前端 Edge AI 路口人車安全偵測實作手冊

本教材完整記載 SafeRoad AI 如何在「零主機採購、零伺服器維護」的條件下，直接於瀏覽器本地執行神經網路模型，實現路口影像目標識別與「未禮讓行人」空間交會衝突演算。

01

計畫動機與學習目標

傳統「科技執法」依賴採購昂貴的專用攝影機與 GPU 主機，導致偏鄉或一般校園周邊難以推廣。本專案核心目標：直接利用既有監視器畫面透過前端邊緣運算，打造平民化的交通安全網。

零主機成本
使用者自己的瀏覽器端運算，省去維護雲端伺服器費用。
保障用路人隱私
影像完全留在前端記憶體處理，不外傳至遠端，無資料洩漏風險。
秒級即時反應
省去上傳與下載的網路來回延遲，50~100ms 內完成推論標註。
02

核心名詞「大白話」速查表

報告或技術問答時，可使用以下生活化比喻清楚表達概念：

專業技術名詞 白話怎麼講 直覺生活比喻
邊緣運算 (Edge AI) 「直接在使用者網頁裡面跑 AI」 像自己拿計算機算題目，不用每題打電話回總部問。
模型推論 (Inference) 「模型看照片、認出東西的過程」 就像眼睛看到照片，大腦在 0.1 秒內反應出「那是機車」。
特徵提取 (Feature Extraction) 「AI 抓出車輪、把手或人臉輪廓」 人認機車不是死背整張照片，而是認「兩個輪子加車把」。
非極大值抑制 (NMS) 「刪掉重複畫出的邊界框」 AI 框同一台車畫了 5 個重疊框，只留下分數最高的那 1 個。
Roboflow API 「把照片傳給特定訓練好的雲端大腦」 像用通訊軟體把照片傳給專家，請專家在 0.5 秒內圈出答案回傳。
03

系統運作流程與偵測原理

[上傳路口街景] ──> [前端 Canvas 提取張量] ──> [深度神經網路特徵分析] ──> [篩選交通實體 (人/車)] ──> [人車交會衝突演算] ──> [紅框告警 / 綠框常態]

第一階段：AI 目標檢測（辨識人與車）

神經網路將圖片正規化並抽取高階幾何特徵，預測出物體分類與邊界框座標 $(x, y, w, h)$。系統將過濾信心門檻定為 0.35，有效排除街景地圖圖標等背景雜訊。

第二階段：未禮讓行人衝突判定（決策邏輯）

系統將辨識目標分類為「弱勢行人（`person`）」與「動力載具（`car/motorcycle/bus/truck`）」：

常態通行（安全綠標）
畫面中僅有單純車流通行，或僅有行人在安全範圍活動，無空間路權衝突。
未禮讓行人（高風險紅標）
路口交會動線上同時鎖定穿越行人與行駛車輛，自動觸發紅色告警並提醒停讓。

模型架構評估與選型

評估指標 方案 A：YOLOv8n (ONNX Runtime) 方案 B：MobileNetV2-SSD (TFJS)
檔案體積 約 12 MB (單一二進位模型檔) 約 2 ~ 3 MB (切碎分段加載)
校園網路相容性 易受 TANet 防火牆阻擋或連線逾時 極佳，各類平板、學校桌機秒開秒跑
推論精確度 高，對高密度機車辨識度極佳 優良，滿足展示與原型驗證需求
專案最佳定位 本機開發環境 / 高階終端測試 線上 GitHub Pages 成果展示
05

核心程式實作精華（四步法）

步驟 1：引入輕量化 CDN 腳本
<!-- 引入 TensorFlow.js 與 COCO-SSD 目標檢測函式庫 -->
<script src="https://cdn.jsdelivr.net/npm/@tensorflow/tfjs@4.10.0/dist/tf.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/@tensorflow-models/coco-ssd@2.2.2/dist/coco-ssd.min.js"></script>
步驟 2：非同步加載模型並進行偵測
// 非同步加載輕量化模型
const model = await cocoSsd.load();

// 輸入上傳之路口圖片並取得預測清單
const predictions = await model.detect(imgElement);
步驟 3：過濾目標並判定人車衝突
// 1. 篩選信心值大於 0.35 之人與車
const targets = predictions.filter(p => p.score >= 0.35 && ['person', 'car', 'motorcycle'].includes(p.class));

// 2. 判定是否同時存在行人與車輛
const hasPerson = targets.some(t => t.class === 'person');
const hasVehicle = targets.some(t => ['car', 'motorcycle'].includes(t.class));
const isConflict = hasPerson && hasVehicle; // 觸發未禮讓行人告警
步驟 4：動態 Canvas 標註繪圖
// 若有衝突顯示紅色，無衝突顯示綠色
ctx.strokeStyle = isConflict ? '#ef4444' : '#10b981';
ctx.strokeRect(x, y, width, height);
06

實務除錯心得（工讀生踩坑經驗分享）

踩坑 1：學校電腦開網頁一直「轉圈圈卡死」

原因：代碼寫死讀取本地 ./yolov8n.onnx（12MB），但 GitHub 未上傳該二進位檔；備用 CDN 又遭學校 TANet 防火牆阻擋。
解法：展示端改用分段加載的 coco-ssd，檔案僅 2MB，學校網路與手機行動數據皆能秒開。

踩坑 2：高解析度街景照片上「標籤字體變米粒」

原因：固定設定 font: 14px，遇到 4K 或高解析度照片時，字體相對縮小至無法閱讀。
解法：改採畫面寬度百分比計算 Math.floor(img.naturalWidth * 0.022)，無論解析度高低皆能清晰呈現。

07

下階段後端演進規劃 (Roadmap)

目前前端版本已成功驗證「邊緣即時辨識之可行性」。若後續計畫需串接實體路口監視器連續影像，架構演進規劃如下：

1. 連續串流介接 (RTSP / RTMP)
採用 Python FastAPI + OpenCV 解碼路口監視器即時影格。
2. 動態軌跡追蹤 (ByteTrack)
計算車輛行駛向量與車速，精準過濾路邊「靜止停放」之死車。
3. 事件日誌與資料庫 (PostgreSQL)
觸發未禮讓行人時，自動保存違規影像截圖並寫入違規資料表。
4. 自訂路口標註模型 (Roboflow)
訓練台灣特殊無號誌標線與混流車種專屬權重檔。
